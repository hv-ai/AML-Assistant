# Public feedback pilot

The custom web UI and Python backend can run on Render or Replit. Streamlit Community Cloud requires a Streamlit application; this is a different UI implementation.

## Recommended low-traffic portfolio host: Render Free

1. Put the contents of the clean deployment ZIP into a dedicated GitHub repository. Include `data/processed/chunks.json`, `config/deployment_retrieval.json`, the public evaluation reports, `web/`, and `src/`. The ZIP already contains these. Do not upload `.env`, `.runtime`, `.venv`, account databases, or personal session exports.
2. In Render, choose **New → Blueprint**, connect the repository, and select its `render.yaml`.
3. Confirm that the service plan is **Free**. Enter `NEBIUS_API_KEY` and `PINECONE_API_KEY` in Render's secret environment fields. `SESSION_SECRET` is generated by the Blueprint. No API keys belong in GitHub or the browser.
4. Deploy. Render supplies `RENDER_EXTERNAL_URL`; the app uses it as its permitted origin. The health check is `/healthz`.
5. Open the returned HTTPS URL. Confirm the Hybrid retrieval indicator, open the saved example, ask one question, inspect a citation, refresh, and open a news brief. Share only this published URL after those checks.

Manual web-service settings, if not using Blueprint: Python runtime, `pip install -r requirements.txt`, start command `gunicorn -c gunicorn.conf.py --access-logfile /dev/null hosted:app`, Free instance, `/healthz` health check. Add the same secrets and model names from the Blueprint; generate a random `SESSION_SECRET` of at least 32 characters.

Render's free service sleeps after 15 minutes without inbound traffic; waking can take about a minute. Its filesystem is ephemeral across restart, sleep and deployment. The code, policy corpus, evaluation reports and saved example remain in the deployed source. Browser-tab history remains in the visitor's browser, not the hosting filesystem. Runtime answer caches and request counters can reset. Hosting policies and free allowances can change; there is no five-month availability guarantee.

## Replit alternative

Import the clean ZIP as a Python project. Install `requirements.txt`; run `gunicorn -c gunicorn.conf.py hosted:app`. `.replit` supplies the run/build commands and port mapping.

For a public deployment, add Nebius/Pinecone keys as Replit Secrets, a random `SESSION_SECRET` of at least 32 characters, and `PUBLIC_ORIGIN` equal to the exact published HTTPS URL. The hosted entry point refuses incomplete origin/secret configuration. Publish with one server instance; do not use a static deployment because the app needs a Python backend. Check the Publishing estimate and account spending controls before launch. Core subscription and deployment usage are separate billing concepts; included credits are consumed by eligible usage and do not guarantee free indefinite hosting.

## Pilot controls and limitations

- Guest-only public routes; no account creation, account database endpoints or public model selector. Only the configured model can be called.
- Signed, secure, HttpOnly session cookie identifies a browser for request limiting; this is not a user account. Research/history stays in `sessionStorage` in each tab. Public content and a random visitor identifier are the only cookie contents.
- Up to 10 AI request attempts per browser per UTC day and 50 overall per UTC day, plus 30 API attempts per browser per minute. Cached answer/brief requests count conservatively toward this pilot allowance. Sources-only search does not consume the AI allowance.
- Three concurrent AI slots, one Gunicorn process, one hosting instance. SQLite counters and file caches do not coordinate across instances. This is intended for a small feedback pilot, not high-scale service.
- Global provider guards also remain: 100 generation attempts and 150 embedding batches per runtime filesystem. These are not dollar caps and reset if ephemeral storage is lost. Visitors can reset their cookie; the shared counter still applies within one runtime. Configure provider-side spending/quota controls, review actual usage, and pause live calls when credits end. App limits alone cannot promise a fixed monthly bill.
- Official feeds use a shared one-hour cache; public refresh cannot force repeated upstream fetches. The app does not run daily background ingestion while no one visits.
- PDF coverage is bounded: at most two directly linked PDFs from the issuing regulator's approved hosts, 6 MB each, first 50 pages / 160,000 characters, six selected passages per document. Scanned PDFs need OCR. Other attachments and external-host documents are not silently treated as read.
- A local package does not update an existing deployment. Apply changes and republish in the hosting account, then verify the published URL.

## Keeping a useful portfolio demo after credits expire

The **View saved example** button loads a labelled, previously generated result from the public evaluation report without an API call. Sources-only search also works without model credit. Live answers and newly generated news briefs require valid provider access and funds. The saved example is a dated corpus demonstration, not a current-law answer or a substitute for live generation.
